# Session 5 — Opus 5 — Independent readiness review / go-no-go

Act as sceptical reviewer, not advocate or builder. Read repo, implementation plan, contracts, threat boundaries, test evidence, current diff and runbook. Do not take implementation agent's claims on trust.

Review for:
- Learning effectiveness: human independent notes, meaningful critique, separate facts/inferences, cheap experiments.
- Product: timing, accessibility, data export, facilitator resilience, offline mode.
- Copilot: skill compatibility PROVEN vs assumed, agent shareability and fallback, prompt-injection resilience.
- Security: no external endpoints or leaked personal/corporate information, approved deployment controls.
- Story: synthetic account-transfer reveal changes interpretation, not retroactively invented truth.
- Test evidence: commands, results, skipped checks, real work-machine browser acceptance.

Output: BLOCKERS / MATERIAL RISKS / NITS, with file locations, reproduction steps and suggested fixes. State GO or NO-GO for (a) solo demo, (b) participant workshop, separately. Suggest smallest next actions. Do not merge, push, install globally, publish or claim review complete unless it is.
