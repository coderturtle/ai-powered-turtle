# Design reference

Positioning: polished cinematic engineering-lab meets friendly rubber duck mascot; mature, not childish. Projector-first and phone-responsive.

Colours: ink #111B28, yellow #FACC15, teal #0D9488, light #F8FAFC, slate #475569. No external font downloads; use system UI fallback.

Core projected screen: header [Operation Rubber Duck / Mission 03 of 07], giant mission headline, readable exercise instruction, large countdown, 'Think / Challenge / Decide' phase marker, next mission preview. Facilitator overlay offers skip/back/pause/extend/wildcard.

Participant screen: mission title, objective, team role, 'Copy prompt' action (real clipboard with fallback), approved Copilot shortcut when configured, editable local evidence and Passport, review checkpoint, manual next-stage action.

Agent cards: four distinct duck personalities, action and skill name, no provider-specific fake direct integration.

Important: the site is not a Copilot API front-end; it guides and links to approved Copilot experiences. No network after initial asset load.
