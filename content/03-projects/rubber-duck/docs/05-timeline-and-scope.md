# Suggested scope gates

**Slice 0 — environment and scenario:** corporate capability spike, coherent fictional demo, contract + 15-min story. Gate: human understands twist.

**Slice 1 — one workflow:** The Duck → Mirror → Quackquisition using portable Passport and plain prompts. Gate: nontechnical participant completes unaided in rehearsal.

**Slice 2 — native skills:** author-facing four personal agents with tenant-native skills; verify successful invocation and fallback. Gate: each instruction survives a deliberately misleading prompt.

**Slice 3 — facilitator UI:** local static site, timers, mission cards, passport editor, exports, offline rehearsal. Gate: no runtime external dependency.

**Slice 4 — Hatchery and room experience:** interventions, experiment, voting, printables, visual polish. Gate: complete 105-minute dry run with changed diagnosis evidence.

**Defer:** multiuser sync, AI-generated confidence, enterprise integrations, external Strata, elaborate animations, video or live data. Add only after a successful end-to-end rehearsal.
