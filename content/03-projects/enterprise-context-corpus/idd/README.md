# IDD Add-on Pack

Merge this folder into the Enterprise Context Corpus starter pack.

Suggested locations:
- `docs/idd-context-pack.md`
- `idd/schemas/*`
- `idd/templates/*`
- `idd/skills/*`
- `idd/agents/*`
- `idd/examples/*`

Start with the context pack, then scaffold only the minimal files needed in a target repo.

Do not build an IDD runtime initially. The MVP is:
- files;
- schemas;
- skills/prompts;
- deterministic validation;
- evidence-backed verification.
