# Skill: /intent-close

Close the current intent only after independent verification.

Check:
- all acceptance criteria have evidence;
- no unresolved blockers;
- material decisions captured;
- temporary exceptions recorded;
- potential debt/divergence reviewed.

Return one:
- COMPLETE
- COMPLETE_WITH_DEBT
- BLOCKED
- NEEDS_REWORK

If closing, update intent status and preserve the evidence record.
