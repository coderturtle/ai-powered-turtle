# Axiom

**The strategy golden source.**

Axiom is a lightweight, agent-first repository that is the authoritative source for three initially related technology strategies:

- AI Organisation Strategy
- Platform Strategy
- Platform Engineering Operating Model Strategy

Core thesis:

> Git is the golden source for strategy. AI is the primary interface. Confluence, HTML, graphs, caches and pre-reads are derived projections.

The MVP deliberately avoids direct LLM API plumbing, vector databases, graph databases, a bespoke chat UI, and two-way Confluence sync.

See [[README|the pack README]] for the reading order, plus the supporting docs and prompt in this folder:

- `docs/context-pack.md` — build context: mission, scope, structure and constraints
- `docs/research-findings.md` — prior art and patterns to borrow
- `docs/open-design-questions.md` — questions to resolve experimentally
- `prompts/01-opus-plan.md` — Opus planning prompt
- `manifest.json`
