# Strategy Golden Source — Context Pack

Use this pack as the durable planning context for an internal Claude Code build.

Core thesis:

> Git is the golden source for strategy. AI is the primary interface. Confluence, HTML, graphs, caches and pre-reads are derived projections.

Start with:
1. `docs/context-pack.md`
2. `docs/research-findings.md`
3. `docs/open-design-questions.md`
4. `prompts/01-opus-plan.md`

The MVP deliberately avoids direct LLM API plumbing, vector databases, graph databases, a bespoke chat UI, and two-way Confluence sync.
